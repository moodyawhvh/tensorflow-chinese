# TensorFlow C++ 示例

本目录包含 TensorFlow C++ API 的示例(以及一些跳转说明)。如果你要找的不是这些,可以参考以下链接:

*   TensorFlow Python 示例见
    [tensorflow.org 上的教程](https://tensorflow.org/tutorials)
*   社区维护的 Keras 示例见
    [keras.io/examples](https://keras.io/examples/)
*   TensorFlow Lite 示例见
    [tensorflow/examples 仓库](https://github.com/tensorflow/examples/tree/master/lite)
*   Udacity 课程笔记本见
    [该目录](https://github.com/tensorflow/examples/tree/master/courses)

## 关于这些示例

*   C++ API 只能方便地在 TensorFlow 的 `bazel` 构建体系内编译。如果你需要独立构建,
    [请参考 C API](https://www.tensorflow.org/install/lang_c)。
*   本目录不再积极维护。
